# Round 3: re-test with independent rainfall (GPCP) (16 Oct 2026)

Question from round 2: SOI fitted rain better than the official ONI. Was that because SOI and rain both came from ERA5?

Numbers from `results/correlations_r3.csv`, `soi_oni_gap_bootstrap_r3.csv`, `gpcp_yearly_r3.csv`, `gpcp_cells_r3.csv`, produced by `src/analyse_r3.py` in this commit. GPCP v2.3 monthly file supplied by Toni (NOAA PSL, downloaded 16 Oct 2026), saved unchanged. GPCP is satellite + rain-gauge based and independent of ERA5. It covers Jan 1979 to Jun 2026 (Nov 2021 onward is interim), so every test here uses **1979–2025 (n=47)** for both rain sources.

GPCP cells used (nearest 2.5° cell centre to each ERA5 point): Riau 1.25N 101.25E; Jambi 1.25S 103.75E; South Sumatra 3.75S 103.75E; West Kalimantan 1.25S 108.75E; Central Kalimantan 1.25S 113.75E; South Kalimantan 3.75S 113.75E.

## 1. Do ERA5 and GPCP agree?

Yes. Aug–Oct rain, 1979–2025: Sumatra r = 0.908, Kalimantan r = 0.926.

## 2. SOI vs ONI, with each rain source (same 47 years)

| | ERA5 rain | GPCP rain |
|---|---|---|
| Sumatra: SOI | r = 0.807 | r = 0.768 |
| Sumatra: ONI | r = −0.692 | r = −0.741 |
| Kalimantan: SOI | r = 0.874 | r = 0.905 |
| Kalimantan: ONI | r = −0.698 | r = −0.821 |

Gap |r(SOI)| − |r(ONI)|, with 95% bootstrap interval (10,000 paired resamples of years):

| | ERA5 | GPCP |
|---|---|---|
| Sumatra | 0.115 (0.023 to 0.223) | 0.027 (−0.068 to 0.125) |
| Kalimantan | 0.176 (0.086 to 0.271) | 0.084 (0.015 to 0.158) |

**Reading:**
- **Part of the SOI advantage was the shared ERA5 source.** With independent rain the gap shrinks by about three-quarters for Sumatra (and is no longer distinguishable from zero) and by about half for Kalimantan.
- A smaller SOI advantage remains for Kalimantan with GPCP. That fits SOI tracking the atmosphere directly, but one interval near zero is not strong evidence.
- **The El Niño → rain link itself is not an artefact.** With independent rain and the official ONI it is as strong or stronger: Kalimantan r = −0.821, Sumatra r = −0.741 (both p < 0.0001).

## 3. Indian Ocean Dipole, with GPCP

| DMI with ONI held fixed (partial r), 1979–2025 | ERA5 | GPCP |
|---|---|---|
| Sumatra | −0.432 (p = 0.0027) | −0.551 (p = 0.0001) |
| Kalimantan | −0.155 (p = 0.30) | −0.314 (p = 0.033) |

With independent rain the IOD effect is **larger** than ERA5 shows, and clearly stronger for Sumatra than Kalimantan. That is consistent with Sumatra facing the Indian Ocean. (Round 2's ERA5 partials used 1950–2025, so this table is the like-for-like comparison.)

## 4. GPCP rain → Singapore haze (2016–2025, n=10)

| | Aug–Oct mean PM2.5 | Days PSI > 100 |
|---|---|---|
| Sumatra rain | r = −0.800 (p = 0.0055) | r = −0.562 (p = 0.091) |
| Kalimantan rain | r = −0.805 (p = 0.0050); Spearman −0.879 | r = −0.444 (p = 0.20) |

Drier Aug–Oct (by an independent record) goes with higher Singapore PM2.5. Unhealthy-day counts remain too sparse to test.

## What changes from rounds 1–2

1. Round 1's SOI-based numbers overstated how much better SOI is than ONI; use ONI (official) with GPCP (independent) as the headline pair from now on.
2. The core chain El Niño → drier Aug–Oct → higher Singapore PM2.5 holds with independent data on both links.
3. The IOD matters more than round 2 suggested, especially for Sumatra.

## Limits

- GPCP 2.5° cells are coarse; some cells include sea.
- Singapore link still n = 10, no 2015; 2019 understated.
- Tests across rounds 1–3 now 37 + 20 = 57, no multiple-comparison correction.
- GPCP after Nov 2021 is interim.
